# blocks-editor

A self-contained Vite + React sample that demonstrates the whole agent-cms stack
in one vertical slice: an **agent-cms schema** → **`@agent-cms/codegen`** →
a **mounted result-rpc router** → a **browser client** → a **custom DAST editor**
with slash-commands and embedded-block support.

No wrangler, no D1, no R2, no deployed resource — the CMS's Effect services run
in-process against a local SQLite file, and the result-rpc router serves both
`/rpc` and the built SPA from one Node process.

## The stack, end to end

1. **`schema.json`** — a `post` model with a `content` `structured_text` field
   that allows five embedded block types (`hero_section`, `code_block`,
   `image_gallery`, `feature_card`, `feature_grid`).
2. **`src/cms/`** — generated by `@agent-cms/codegen` from that schema:
   `contract.ts` (browser-safe wire codecs + the block-payload union) and
   `procedures.ts` (server handlers running agent-cms in-process).
3. **`src/contract.ts`** — the host contract: the CMS fragment plus one
   host-owned procedure, in **one** result-rpc contract/client.
4. **`server/index.ts`** — a Node process that builds a `SqliteClient` layer,
   registers the schema, seeds one post (through the real procedure path via
   `createServerClient`), mounts `cmsProcedures` + the host procedure into a
   router, and serves `createFetchHandler` at `/rpc` + the SPA from `dist/`.
5. **`src/editor/`** — the custom DAST editor:
   - `slash.ts` — a headless ProseMirror plugin that detects `/query`.
   - `SlashMenu.tsx` — the popup (filtering, keyboard nav, commit).
   - `blocks.tsx` — `newBlock` drafts + per-type `BlockView` rendering.
   - `DastEditor.tsx` — `useDastEditor` + mark toolbar + slash menu.

## Run it

```bash
pnpm install        # from the repo root (first time)
pnpm --filter blocks-editor codegen   # regenerate src/cms from schema.json
pnpm --filter blocks-editor build     # typecheck + Vite build
pnpm --filter blocks-editor start     # http://localhost:8790
```

Open <http://localhost:8790>, pick a post, and type `/` anywhere in the editor to
insert headings, lists, tables, quotes, code, or an embedded block. **Save** and
reload to confirm persistence (the SQLite file lives in `.demo/`).

`src/cms/` is checked in; regenerate it after editing `schema.json` with
`pnpm --filter blocks-editor codegen`.
